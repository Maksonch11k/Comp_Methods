### Малоранговые приближения и сжатие изображений

## Часть 1

**0. описание формата**
Формат **SVDZ** (SVD Zipped) — бинарный формат хранения изображений, использующий 32-битные числа с плавающей точкой (`float32`).

**1.назначение**
Формат предназначен для хранения сжатого представления монохромных BMP изображений с использованием теории малоранговых приближений.позволяет контролировать размер файла за счет усечения количества сингулярных чисел (ранга $k$).

**2. структура файла**
Файл состоит из заголовка фиксированной длинны (16 байт) и области данных

*   **a. [0-3]** `signature` : `char[4]` — Сигнатура формата (фиксированное значение `b'SVDZ'`).
*   **b. [4-7]** `height` : `uint32` — Высота изображения ($H$).
*   **c. [8-11]** `width` : `uint32` — Ширина изображения ($W$).
*   **d. [12-15]** `rank` : `uint32` — Ранг приближения ($k$), количество сохраненных сингулярных чисел.

**3. данные**
данные записаны последовательно сразу после заголовка в формате IEEE 754 `float32`

*   **a.** `U` : `float32[H * k]` — матрица левых сингулярных векторов
*   **b.** `S` : `float32[k]` — вектор сингулярных чисел
*   **c.** `Vt` : `float32[k * W]` — Матрица правых сингулярных векторов (транспонированная).

*Общий размер файла:* $16 + 4 \cdot (H \cdot k + k + k \cdot W)$ байт

**4. Алгоритм работы**

*   **a. Сжатие:**
    1.  Исходное изображение `.bmp` конвертируется в матрицу яркости
    2.  выполняется сингулярное разложение матрицы $A = U \Sigma V^T$
    3.  вчисляется максимально допустимый ранг $k$ исходя из требуемого коэффициента сжатия $N$
    4.  Матрицы усекаются: оставляются только первые $k$ столбцов $U$ первые $k$ чисел $S$ и первые $k$ строк $V^T$
    5.  Результат записывается в бинарный файл `.svdz`

*   **b. Восстановление:**
    1.  Чтение метаданных ($H, W, k$) из заголовка
    2.  Загрузка массивов $U, S, V^T$
    3.  Матричное перемножение: $A_{approx} = (U \cdot S) \cdot V^T$.
    4.  нормализация значений в диапазон [0, 255] и сохранение в `.bmp`

## Примеры работы алгоритма (N = 2, 4, 8)

**Анализ результатов:**
1.  **Градиент (ex1_gradient):** Изображение имеет естественный низкий ранг. Визуальных потерь качества нет даже при $N=8$, так как основная информация содержится в первых нескольких сингулярных числах
2.  **Круг (ex2_circle):** При $N=8$ наблюдается эффект звон вокруг резких границ круга так как высокие частоты были отброшены
3.  **Шум (ex3_noise):** качество страдает сильнее всего. изображение теряет детализацию и превращается в набор крупных пятен так как шум имеет полный ранг и его невозможно сжать без потери информации

## Часть 2. Сравнение алгоритмов SVD

**1. метод эксперимента**
Для демонстрации значимых различий между алгоритмами `numpy.linalg.svd` и `scipy.linalg.svd` было сформировано специальное тестовое изображение размера $800 \times 533$.

изображение генерировалось по следующей формуле:
$$A_{i,j} = (i \cdot j) \pmod{256}$$

Полученная матрица была сохранена в формат `.bmp` и загружена обратно для имитации реальной работы с файловой системой и 8-битными данными

**2. Вычисление и метрика**
Сингулярное разложение выполнялось двумя библиотеками:
1.  **Numpy:** Стандартный вызов `np.linalg.svd(A)`.
2.  **Scipy:** Вызов с указанием драйвера `scipy.linalg.svd(A, lapack_driver='gesvd')`. Использование QR-алгоритма (`gesvd`)позволяет получить иной профиль ошибок округления.

для оценки различия векторов сингулярных чисел $\sigma^A$ (Numpy) и $\sigma^B$ (Scipy) использовалась метрика $L_2$ вектора отношений $c$:

$$c_k = \max\left(\frac{\sigma^A_k}{\sigma^B_k}, \frac{\sigma^B_k}{\sigma^A_k}\right)$$
$$Metric = ||c||_2 = \sqrt{\sum c_k^2}$$

**3.результ**
в ходе эксперимента было получено экстремально высокое значение метрики (порядка $10^{30} \dots 10^{32}$).
