
# Решение интегральных уравнений методом сплайн-коллокаций

## описание лабы

Данный проект представляет собой реализацию на языке Julia численного метода для решения интегральных уравнений Фредгольма (I и II рода) и Вольтерра (II рода). Основой метода является **сплайн-коллокация**, где искомое решение аппроксимируется линейной комбинацией B-сплайнов


Реализация B-сплайнов взята из предыдущей лабы, можно улучшить точность если использовать встроенные B-сплайны

## Структура проекта


*   `utils.jl`: Содержит базовую реализацию для работы с B-сплайнами
*   `fredholm_solvers.jl`: Включает решатели для уравнений Фредгольма:
    *   `solve_fredholm_II`: Решает уравнение II рода
    *   `solve_fredholm_I_via_Wazwaz_regularization`: Решает уравнение I рода путем его преобразования в уравнение II рода в соответствии со статьей номер 3 из источников
*   `volterra_solver.jl`: Содержит функцию `solve_volterra_II` для решения уравнений Вольтерра II рода
*   `main_experiment.jl`:  скрипт для проведения численных экспериментов. Он запускает решатели на наборе тестовых уравнений, вычисляет ошибку, строит графики

### Часть 2: Уравнение Фредгольма I рода

уравнения этого типа `∫[a,b] K(t,x)u(x)dx = g(t)` являются некорректно поставленными. Для их решения был применен метод регуляризации, преобразующий их к виду: `u_α(t) - ∫[a,b] (-1/α)K(t,x)u_α(x)dx = (1/α)g(t)`

**выбор параметра**: Выбор параметра регуляризации `alpha` является критически важным для баланса между подавлением шума и точностью. был реализован автоматический поиск оптимального `alpha` от 0.1, до 0.0001

**Пример 2.1: Гауссово ядро**
*   **Уравнение**: `∫[0, 1] exp(-(t-x)²)u(x)dx = g(t)`
*   **Точное решение**: `u(t) = 1 + sin(2πt)`
*   **Результаты**:

    ```

    Найден оптимальный alpha = 0.1 с минимальной ошибкой = 2.225304738425025

    ```

**пример 2.2: Ядро `cos(tx)`**
*   **уравнение**: `∫[0, 1] cos(tx)u(x)dx = g(t)`
*   **точное решение**: `u(t) = 1 + t`
*   **Результаты**: Аналогично первому примеру, подбор `alpha` позволил получить устойчивое решение

```

Найден оптимальный alpha = 0.1 с минимальной ошибкой = 3.2722117560147943

```
### Часть 3: Адаптация метода для уравнений Вольтерра

На этой части мы отвечаем на вопросы, поставленные в задании, исследуя уравнение вида `u(t) - ∫[a,t] K(t,x)u(x)dx = f(t)`

#### Получится ли это сделать?

да, формально адаптировать решатель возможно изменив верхний предел интегрирования с константы `b` на переменную `t`. Это было реализовано в функции `solve_volterra_II`

метод, который мы реализовали по своей природе **глобальный** а уравнения Вольтерра требуют **локального (последовательного)** подхода.

*   **Глобальный метод (для фредгольма)**: Наш решатель строит одну большую матрицу `M` для всего интервала `[a, b]` и находит все коэффициенты сплайнов `c` **одновременно**. Он "смотрит" на весь интервал сразу

*   **локальный/Последовательный подход (требуется для вольтерра)**: Уравнения Вольтерра обладают "памятью" или **причинностью**. Решение в точке `t` зависит только от значений в прошлом `[a, t]`. Правильные численные методы для них строят решение шаг за шагом, двигаясь слева направо по интервалу. Матрица системы для них всегда **нижнетреугольная**.

Наша реализация `solve_volterra_II` строит **плотную (не нижнетреугольную) матрицу `M`**. Это приводит к двум проблемам:

1.  **неэффективность**: Решение плотной системы `(I-M)c = μ` требует O(n³) операций вместо O(n²) для треугольной.
2.  **численная неустойчивость**: Глобальный подход очень чувствителен к накоплению ошибок. Небольшая ошибка в начале интервала `[0, 2π]` может многократно усиливаться и "взрываться" к концу интервала

### Решение: Как исправить

1.  **ииспользовать математически корректный и более устойчивый пример.** Давайте возьмем более простой пример, где ядро и решение не вызывают сильных колебаний, и исправим правую часть.
2.  **значительно уменьшить интервал интегрирования.** На коротком интервале (например `[0, 1]`) глобальный метод еще может дать приемлемый результат до того как ошибки накопятся и взорвутся
