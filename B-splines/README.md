# Интерпретация результатов численного эксперимента

В ходе эксперимента были сравнены две схемы аппроксимации квадратичными B-сплайнами: аппроксимация уменьшающая вариацию и аппроксимация на основе трехточечного функционала.Для анализа были выбраны три тестовые функции каждая из которых подчёркивает сильные и слабые стороны методов

## 1. гладкая функция: `f(x) = sin(2πx)`

*   **мотивация выбора:** это пример гладкой бесконечно дифференцируемой функции который позволяет оценить максимальную достижимую точность и порядок сходимости методов

*   **Наблюдаемый результат:**
    *   Метод на основе **трехточечного функционала** демонстрирует на порядки более высокую точность. Ошибка для этого метода убывает с коэффициентом ~16 при каждом удвоении числа узлов что сответствует порядку сходимости `O(h⁴)`.
    *   Метод, **уменьшающий вариацию** показывает значительно большую ошибку которая убывает с коэффициентом ~4 что соответствует порядку `O(h²)`

*   **Вывод:** Для аппроксимации гладких функций трехточечный метод является несравненно более эффективным и предпочтительным

## 2. Функция с разрывом: `f(x) = sign(x - 0.5)`

*   **мотивация выбора:** данная функция имеет разрыв первого рода и позволяет проверить одно из ключевых свойств сплайнов — способность обрабатывать резкие скачки без введения артефактов

*   **Наблюдаемый результат:**
    *   аппроксимация, **уменьшающая вариацию** плностью оправдывает свое название. она создает гладкий переход между уровнями -1 и 1, не производя новых локальных экстремумов
    *   трехточечный метод напротив генерирует заметные ложные осцилляции в окрестности точки разрыва
    *   хотя формальная максимальная ошибка велика для обоих методов качественное поведение первого метода значительно превосходит второй

*   **Вывод:** Для негладких данных с разрывами метод уменьшения вариации является единственным правильным выбором так как он гарантирует отсутствие артефактов и сохраняет форму исходного сигнала

## 3. функция с изломом: `f(x) = |x - 0.5|`

*   **Мотивация выбора:** Эта функция непрерывна, но её производная имеет разрыв. она моделирует данные с "острыми углами" и позволяет оценить как методы справляются с такими особенностями

*   **Наблюдаемый результат:**
    *   Метод уменьшающий вариацию аккуратно сглаживает острый угол обеспечивая визуально приятное и более точное приближение
    *   трехточечный метод также сглаживает излом, но делает это с небольшим перелётом, что приводит к немного большей максимальной ошибке и менее предсказуемому поведению вблизи особенности

*   **вывод:** В задачах где встречаются изломы и углы метод уменьшения вареации снова показывает себя как боле надежный

## Общее заключение

| метод | Преимущества | недостатки | где лучше использовать |
| :--- | :--- | :--- | :--- |
| **Уменьшающий вариацию** |  отсутствие осцилляций, сохранение формы | Низкий порядок точности | функции с разрывами и изломами. |
| **Трехточечный функционал** | Высокая точность быстрый порядок сходимости | Генерирует осцилляции на негладких данных | Аппроксимация аналитических и других гладких функций |
